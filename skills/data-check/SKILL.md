# 데이터 확인

## 처음 읽을 때

1. 파일별 행·열 수, 컬럼 이름과 타입, 앞 3행을 출력한다.
2. 컬럼별 결측 수와 비율, 고유값 수, 수치 컬럼의 최소·중앙값·최대를 출력한다.
3. 키 후보 컬럼의 중복 수를 센다.
4. 시간 컬럼이 있으면 시작·끝, 간격, 빠진 구간을 확인한다.
5. 정답(라벨) 컬럼이 있으면 클래스 비율을 출력한다.
6. 이상해 보이는 값(음수 수량, 범위 밖 값, 단위가 의심되는 값)은 목록으로 보여 주고 처리 방법을 묻는다.

확인한 가정은 docs/DECISIONS.md의 "데이터 가정"에 적는다.

## 가공할 때마다

- 단계 전후의 행 수와, 빠진 행의 이유별 개수를 출력한다.
- 병합(join)은 전후 행 수와 짝을 못 찾은 키 수를 출력한다. 행이 늘면 중복 키를 의심한다.
- 원자료에서 3행을 골라 결과와 직접 대조하고, 어떤 행을 골랐는지 출력한다.

## 모델·예측을 만들 때

- 시간 순서가 있으면 시간 기준으로 나눈다. 미래 정보가 학습에 섞이면 안 된다.
- 예측 시점에 알 수 없는 컬럼, 정답에서 파생된 컬럼은 입력에서 뺀다.
- 정답이 불균형하면 정확도 대신 담당자 기준에 맞는 지표(재현율, 정밀도, F1 등)를 쓴다.
